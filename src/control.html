MangNotch v1.0.0

Interactive Living Notch & Productivity Companion dengan sentuhan estetika editorial MangNime.

Rust Backend Tauri v2 Win32 Native API Open Source
Media & Live Lyrics Integrasi Windows GSMTC, ekstraksi warna sampul album, dan lirik sinkron real-time.
Native File Shelf Simpan file sementara via Drag-in dari Explorer & Drag-out langsung ke WhatsApp/Discord.
Focus & Hydration Timer Pomodoro kustom dengan chime Web Audio API serta pencatat hidrasi harian.
Smart Proximity Engine Otomatis menyusut saat tertutup tab browser & hilang 100% saat bermain game fullscreen.
